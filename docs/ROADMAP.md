# Roadmap

## MVP (Sprints 0–9, ~12 weeks)

| Sprint | Weeks | Deliverable |
|---|---|---|
| 0 | Pre | Repo, CI, Supabase project, Expo app boots |
| 1 | 1–2 | Auth + profile + phone verification |
| 2 | 3–4 | Listings CRUD + media + geo |
| 3 | 5 | Feed + filters + search |
| 4 | 6–7 | Bidding engine |
| 5 | 8 | Messaging + redaction pipeline |
| 6 | 9 | Stripe Connect + escrow |
| 7 | 10 | Ratings + trust score |
| 8 | 11 | Notifications + admin moderation |
| 9 | 12 | Hardening + Miami closed beta (50 users) |

## Post-MVP (Weeks 13–16)

- Recommendations via pgvector embeddings on listings.
- Saved searches with push alerts.
- Spanish localization (Miami priority).
- Pickup-as-a-service (third user role: Hauler) — bridges back to the hauler-resale hybrid thesis.
- Referral program.

## Phase 2 (Q2 onward)

- Geo expansion: Orlando, Tampa, then Atlanta.
- B2B reseller mode for vetted flippers (fee discount + bulk-bid tools).
- AI listing assistant: photo → title + description + suggested price (using comparable sold listings).
- Logistics partner integrations (Roadie, Dolly, Bellhop) for buyers who can't haul.
